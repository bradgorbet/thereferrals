# The Referrals

Website for The Referrals, an 80s/90s cover band that plays fundraisers for charities.

Live at https://thereferralsband.com (hosted on Netlify).

## Editing the site

- `index.html` is the whole site; band photos live in `img/`.
- Changes go through pull requests. Merging to `main` deploys automatically.
- The booking form uses Netlify Forms (form name `booking`).
